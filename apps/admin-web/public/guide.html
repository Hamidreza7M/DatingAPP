راهنمای پنل مدیریت FastLove

برای اجرای محلی Node.js 20 یا جدیدتر لازم است. از ریشه مخزن دستور npm run admin:dev را اجرا کنید و به http://localhost:4177 بروید. از npx serve برای اجرای پنل استفاده نکنید؛ آن دستور فقط فایل‌های ایستا را ارائه می‌کند و API ورود را ندارد.

ورود آزمایشی

نام کاربری admin و رمز 123456. این رمز فقط برای محیط توسعه است.

امکانات

داشبورد BI، جست‌وجوی کاربران و جزئیات چندتب، پرداخت‌ها، گزارش تخلف، لایک/مچ/دیت، احراز هویت ویدئویی، تیکت پشتیبانی و مدیریت قیمت بسته‌ها.

محدودیت نسخه دمو

اطلاعات فعلی Android روی دستگاه ذخیره می‌شوند و به این پنل متصل نیستند. داده‌های پنل نمونه‌اند و سمت سرور در data/db.json ذخیره می‌شوند. برای اتصال واقعی همه نسخه‌ها باید بک‌اند مرکزی و دیتابیس مشترک ایجاد شود. ویدئوهای این داده نمونه واقعی نیستند؛ فقط اطلاعات درخواست نشان داده می‌شود.

Build

دستور npm run admin:build خروجی کلاینت را مستقل در پوشه dist قرار می‌دهد. API با npm run admin:start اجرا می‌شود. متغیرهای Production باید طبق فایل .env.example در سرویس میزبانی تنظیم شوند.
