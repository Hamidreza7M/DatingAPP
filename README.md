# فست لاو (Fast Love) — نسخه ۲.۲

## تغییرات

- بهبود صفحه کشف و نمایش تعداد سوایپ باقی‌مانده روزانه با تم صورتی/نارنجی شبیه Tinder.
- محدودیت سوایپ روزانه: رایگان ۱۰، پرو ۵۰، وی‌آی‌پی نامحدود.
- صفحه انتخاب اشتراک با انتخاب دوره هفتگی/ماهانه و قیمت‌گذاری نمونه به تومان:
  - پرو: ۹۹٬۰۰۰ تومان هفتگی / ۲۹۹٬۰۰۰ تومان ماهانه
  - وی‌آی‌پی: ۱۴۹٬۰۰۰ تومان هفتگی / ۴۴۹٬۰۰۰ تومان ماهانه
- کاربران رایگان به صفحه «کسانی که تو را لایک کرده‌اند» دسترسی ندارند؛ این قابلیت برای پرو و وی‌آی‌پی فعال است.
- امتیاز تکمیل پروفایل و پیشنهادهای مشخص برای کامل‌تر کردن آن.
- تجربه چت بهتر هنگام باز شدن صفحه‌کلید: پنل ورودی با IME جابه‌جا می‌شود، پیام‌ها به آخر گفتگو اسکرول می‌شوند و نوشتن چندخطی پشتیبانی می‌شود.

## نکته مهم درباره پرداخت

خرید اشتراک در این نسخه **صرفاً نمایشی** است و تراکنش مالی واقعی انجام نمی‌دهد. انتخاب پلن فقط وضعیت اشتراک را در حافظه همان اجرای برنامه تغییر می‌دهد. برای عرضه واقعی باید درگاه پرداخت مناسب، تأیید تراکنش سمت سرور، ذخیره اشتراک و کنترل محدودیت‌ها در بک‌اند پیاده‌سازی شوند. قیمت‌ها نمونه‌اند و پیش از انتشار باید نهایی شوند.

## ساخت

پروژه با Android Studio و Gradle قابل ساخت است. اگر Gradle Wrapper در مخزن موجود باشد:

```bash
./gradlew assembleDebug
```
