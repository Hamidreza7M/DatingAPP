# فست لاو (Fast Love) — نسخه ۲.۱

## تغییرات این نسخه

1. **رفع کرش پروفایل** — عکس‌ها با ایموجی جایگزین شدند (بدون وابستگی به اینترنت)
2. **انتخاب سن با سال تولد** — لیست سال‌های تولد
3. **انتخاب شهر از شهرهای ایران** — با جستجو
4. **UX ساخت پروفایل بهتر** — ۴ مرحله‌ای با نوار پیشرفت
5. **چت با متن + تصویر + صوت** (نمایشی)
