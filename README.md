# فست لاو (Fast Love) — نسخه نمایشی اندروید

اپلیکیشن نمایشی فارسی دوستیابی با تم مدرن و جوان‌پسند.

## ویژگی‌ها

1. **ثبت‌نام دمو با OTP**  
   - ورود با شماره موبایل  
   - کد تأیید تستی: `123456`

2. **ساخت پروفایل**  
   - نام، سن، شغل، شهر، درباره من  
   - انتخاب علایق (حداقل ۳)  
   - افزودن حداکثر ۵ عکس (در دمو با ایموجی)

3. **تاریخچه لایک‌ها**  
   - لیست افرادی که شما لایک کرده‌اید

4. **کسانی که شما را لایک کرده‌اند**  
   - امکان لایک برگشتی و ایجاد مچ

5. **چت با افراد مچ‌شده**  
   - گفت‌وگوی نمایشی (پیام‌ها فقط محلی ذخیره می‌شوند)

6. **تم و فونت مدرن**  
   - رنگ‌بندی صورتی-بنفش جوان‌پسند  
   - تایپوگرافی تمیز و خوانا

## ساخت APK با GitHub Actions

1. محتویات پروژه را در repository قرار دهید و روی شاخه `main` پوش کنید.
2. تب **Actions** → workflow **Build Hamdam APK** (یا نام جدید) را اجرا کنید.
3. از بخش Artifacts فایل APK را دانلود کنید.

## ساخت محلی

نیازمند JDK 17:

```bash
./gradlew assembleDebug
```

APK در مسیر:

```
app/build/outputs/apk/debug/app-debug.apk
```

## نکات دمو

- هیچ سرور واقعی وجود ندارد.
- OTP همیشه `123456` است.
- عکس‌ها با ایموجی شبیه‌سازی شده‌اند.
- پیام‌های چت فقط در حافظه جلسه جاری باقی می‌مانند.
