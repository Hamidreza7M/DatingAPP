# فست لاو (Fast Love) — نسخه ۲.۰

اپلیکیشن نمایشی دوستیابی با تم مشابه تیندر، فونت وزیرمتن و ویژگی‌های کامل دمو.

## ویژگی‌های نسخه ۲

1. **تم تیندر** — پس‌زمینه تیره، کارت تمام‌صفحه با عکس، دکمه‌های گرد صورتی
2. **فونت وزیرمتن** (Vazirmatn) در کل اپ
3. **جنسیت** و **گرایش جنسی** در ساخت پروفایل
4. **انتخاب عکس** از گالری یا دوربین (در دمو شبیه‌سازی شده)
5. **عکس پروفایل واقعی** برای افراد پیشنهادی (از pravatar)
6. **بلاک کردن** کاربران
7. **فیلتر پیشرفته**: سن، شغل، علایق، فاصله
8. **لوگوی قلب** روی آیکون و صفحه ورود

## ساخت APK

```bash
./gradlew assembleDebug
```

یا از GitHub Actions workflow استفاده کنید.

## نکات دمو

- OTP همیشه `123456`
- عکس‌های گالری/دوربین در دمو با ایموجی شبیه‌سازی می‌شوند
- عکس افراد پیشنهادی از اینترنت لود می‌شوند (نیاز به اینترنت)
- پیام‌ها و داده‌ها فقط در حافظه جلسه جاری هستند
