# گزارش قابلیت‌های Demo

همه‌ی موارد زیر با داده‌ی نمونه و Mock Repository کار می‌کنند و در ذخیره‌سازی محلی باقی می‌مانند. هرجا رفتار شبیه‌سازی‌شده است، برچسب «دمو» در UI دیده می‌شود.

## چیزهایی که عمداً دمو/آینده‌اند
- Backend، دیتابیس ابری، احراز هویت واقعی، پیامک، پرداخت.
- Photo Verification واقعی، تماس صوتی/تصویری واقعی.
- کاشی‌های واقعی نقشه (osmdroid/MapKit) و آپلود عکس واقعی — هر دو به‌صورت Adapter پلتفرمی قابل افزودن.
