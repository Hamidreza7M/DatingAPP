# FastLove Central API — planned

این مسیر برای بک‌اند مرکزی چندکلاینتی رزرو شده است و هنوز پیاده‌سازی نشده است.

**مهم:** `apps/admin-web/server.mjs` فقط API مستقل نسخه دمو پنل مدیریت است؛ دیتابیس JSON آن منبع داده مشترک Android/iOS/Web User نیست.

در مرحله بک‌اند مرکزی، سرویس باید مسئول این حوزه‌ها باشد:

- احراز هویت کاربران و مدیران، نقش‌ها و مجوزها (RBAC)
- پروفایل، جست‌وجو، لایک، مچ، چت و دیت‌ها
- پرداخت، کیف پول/اعتبار و قیمت قطعی بسته‌ها
- گزارش‌های تخلف، احراز هویت ویدئویی و تیکت پشتیبانی
- فایل‌های خصوصی، اعلان‌ها و رویدادهای تحلیلی محصول
- Audit Log، سیاست نگهداری و حذف داده و محافظت از اطلاعات شخصی

پیشنهاد پایگاه داده Production: PostgreSQL؛ برای فایل‌های خصوصی از Object Storage سازگار با S3 و برای رویدادها/اعلان‌های بلادرنگ از سرویس جداگانه استفاده شود.
